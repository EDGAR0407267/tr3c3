# TR3C3 image slots

These files are intentionally named as final production slots so the first build behaves like the real site:

- `hero-tr3c3-coffee-brunch.webp`
- `brunch-table.webp`
- `specialty-coffee.webp`
- `kitchen-evening.webp`
- `interior-cafe.webp`
- `croissant-coffee.webp`

Replace them with optimized real photographs using the same filenames when the local has final brand imagery. Keep WebP or AVIF versions, preserve similar aspect ratios, and update alt text if the subject changes.
